## Overview

| | |
|---|---|
| **Subscriptions** | 20 independent feeds, up to 2,000 configurations each |
| **Bot Feed** | 1 dedicated feed, up to 5,000 configurations |
| **Protocols** | VLESS, VMess, Trojan, Shadowsocks |
| **Validation** | TCP reachability, TLS / WebSocket handshake, end-to-end proxy request (VLESS and Trojan) |
| **Selection** | Port, host and subnet diversity limits, so no single port dominates a feed |
| **Refresh** | Automatically every 3 hours |
| **Tag** | `#nukcrow` on every configuration |

---

## Quick Start

1. Copy the link of any subscription below.
2. Open your client and choose **Add subscription** (or *Import from URL*).
3. Paste the link, update the subscription, then run a latency test and connect.

> Start with **Subscription 01**. If it is unstable on your network, move to the next one.

Compatible with v2rayNG, v2rayN, Hiddify, Streisand and any client that supports standard subscription links.

<details>
<summary><b>How configurations are selected</b></summary>

1. Sources are collected from curated public repositories and Iran-focused collectors.
2. Invalid, duplicate and insecure entries are removed (for example VLESS without TLS).
3. Each configuration is scored on protocol, transport, security, port, SNI / Host and CDN fronting.
4. Candidates are tested for TCP reachability, then TLS and WebSocket handshake, then an end-to-end proxy request where the protocol allows.
5. Final lists are built tier by tier, with limits per port, host and subnet.

</details>

<details>
<summary><b>Important notes</b></summary>

- Checks run from outside Iran. They confirm that a server is alive and proxies traffic, but they cannot guarantee access from every ISP or on every day.
- Filtering conditions change often. If one configuration stops working, try another one or refresh the subscription.
- Public configurations are shared infrastructure. Avoid sensitive activity on them.
- Provided for educational and research purposes. Use responsibly and in accordance with local laws.

</details>
