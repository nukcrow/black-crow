## 🐦‍⬛ ABOUT | درباره برنامه

### 🇬🇧 English

**Raptor Config Tester** is a Windows utility designed to collect, organize, test, and identify working V2Ray-compatible configurations from public GitHub repositories.

With automatic collection, duplicate removal, optional TCP port checks, and tunnel connectivity testing, Raptor makes configuration testing easier and more organized.

### 🇮🇷 فارسی

**Raptor Config Tester** یک ابزار ویندوزی برای جمع‌آوری، مرتب‌سازی، آزمایش و شناسایی کانفیگ‌های سازگار با V2Ray از مخازن عمومی GitHub است.

این برنامه با قابلیت جمع‌آوری خودکار کانفیگ‌ها، حذف موارد تکراری، بررسی اختیاری پورت‌های TCP و آزمایش اتصال تونل، فرایند تست کانفیگ‌ها را ساده‌تر و منظم‌تر می‌کند.

## 🚀 HOW TO USE | راهنمای استفاده

### 🇬🇧 English

1. Download Raptor Config Tester.
2. Extract the ZIP archive.
3. Enter the archive password if requested.
4. Run `RaptorConfigTester.exe`.
5. Start collecting and testing configurations.
6. Export working configurations to TXT.

### 🇮🇷 فارسی

۱. برنامه Raptor Config Tester را دانلود کنید.

۲. فایل ZIP را استخراج کنید.

۳. در صورت درخواست، رمز آرشیو را وارد کنید.

۴. فایل `RaptorConfigTester.exe` را اجرا کنید.

۵. جمع‌آوری و آزمایش کانفیگ‌ها را شروع کنید.

۶. کانفیگ‌های سالم را در قالب TXT ذخیره کنید.
